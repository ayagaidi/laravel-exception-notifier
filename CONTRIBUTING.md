# Contributing

Thanks for helping improve Laravel Exception Notifier.

## Before submitting a change

- Keep the change focused on one issue or improvement.
- Verify the package still installs and behaves as expected.
- Avoid unrelated formatting changes.
- Update documentation when behavior or setup changes.

## Pull request checklist

1. Create a descriptive branch.
2. Make and test your change.
3. Use a clear commit message.
4. Open a pull request explaining the problem and the solution.

For bug reports, include the Laravel version, PHP version, reproduction steps, expected behavior, and actual behavior.
